# colagreco.dev

Pagina placeholder personale di Antonio Colagreco, realizzata come sito statico senza dipendenze.
La scena usa due livelli PNG indipendenti per il parallax controllato dal puntatore.

## Avvio locale

```bash
python3 -m http.server 8080
```

Apri `http://localhost:8080` nel browser.

## Pubblicazione

La cartella può essere pubblicata direttamente su qualunque hosting statico. Il dominio canonico
previsto nei metadati Open Graph è `https://colagreco.dev`.
